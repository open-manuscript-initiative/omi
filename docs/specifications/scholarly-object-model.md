# Scholarly Object Model — Legacy Route

:::warning Superseded document

This page previously contained the provisional **OMI-SPEC-009: Scholarly Object Model**.

That provisional identifier and duplicate document have been retired. The canonical specification is now:

**[OMI-SPEC-120 — Scholarly Object Model](./core/scholarly-object-model.md)**

:::

## Migration status

The earlier document described scholarly objects as identifiable, versioned, extensible semantic entities with metadata, relationships, lifecycle, composition, references, behaviours, permissions, and serialization.

Those concepts are represented in the canonical OMI-SPEC-120 specification, which provides the authoritative and more complete model. The duplicate text is no longer maintained independently.

## Identifier migration

| Previous provisional identifier | Canonical identifier |
|---|---|
| `OMI-SPEC-009` | `OMI-SPEC-120` |

New specifications, schemas, examples, and implementations MUST reference `OMI-SPEC-120`.

This legacy route remains available to prevent silent link breakage during the documentation refactoring programme.
