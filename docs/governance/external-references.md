# External references and source reuse

OMI documents independently hosted references to the project and its software here. A listing in a third-party catalogue does not, by itself, constitute an independent quality certification, an endorsement, or a partnership.

## XERJ Corpus Hub — selected source code

On **14 October 2026**, the [XERJ Corpus Hub](https://hub.xerj.org/contributors/vargaijanos) listed **Varga István** as a contributor whose work on [Open Manuscript Studio](https://github.com/open-manuscript-initiative/open-manuscript-studio) was selected for its reference corpus. XERJ presents source-code implementations for retrieval by AI coding agents, with links to the originating repository and attribution to contributors.

The selection references the commit **“Preserve conditional UI while localizing labels”** ([369de7305b](https://github.com/open-manuscript-initiative/open-manuscript-studio/commit/369de7305becf512603fa3484254d5f26ad2f24c)), involving **9 files**, **206 changed lines**, and TypeScript code. The corpus covers the entire repository at the pinned commit, not just the changed files.

The XERJ entry states that inclusion was agreed with the contributor and that its MIT licence review was cleared. This is **inclusion in a reference corpus**, not a XERJ product certification or an OMI partnership.
