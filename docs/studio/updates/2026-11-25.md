# Studio development update — 25 November 2026

The merged source now includes expanded Word interoperability, direct note insertion, formatted note previews and adaptive memory management. RC4 version preparation is under review; distribution channels remain independently verified.

## Expanded Word interoperability

Native DrawingML picture geometry and crops, OMML equations, semantic REF fields, private Word comments and reversible review changes, and consistent content-language tags. Verify complex documents after exchange. [PR #1040](https://github.com/open-manuscript-initiative/open-manuscript-studio/pull/1040).

## Direct note insertion and formatted previews

Insert a note at the cursor or attach it to a selection from the persistent toolbar action. Hover or focus a note anchor to read its formatted contents; click to edit. [PR #1041](https://github.com/open-manuscript-initiative/open-manuscript-studio/pull/1041) · [Direct note insertion and formatted previews](/docs/studio/notes-and-formatting).

## Adaptive memory management

A shared, bounded derived-cache budget, three performance modes, diagnostics and background cache clearing. Android samples available system RAM; actual device and WebView memory measurements remain pending. [PR #1043](https://github.com/open-manuscript-initiative/open-manuscript-studio/pull/1043) · [Adaptive memory management](/docs/studio/performance-and-memory).

The development changes are merged in Studio source. The RC4 version-preparation pull request is separate; a version or package upload does not establish deployment. [RC4](/docs/studio/releases/1.0.0-rc.4).
