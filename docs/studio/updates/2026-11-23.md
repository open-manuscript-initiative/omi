# Studio development update — 23 November 2026

## Studio and EuroOffice are now separate in source

On 23 November 2026, [Studio PR #971](https://github.com/open-manuscript-initiative/open-manuscript-studio/pull/971) was merged. Studio no longer embeds general-purpose EuroOffice editing or registers its legacy Office API routes. EuroOffice is maintained as an independent service. This improves the boundary between **semantic scholarly authoring** and **general office-document editing**.

Studio's native DOCX import/export remains available, together with notes, publishing, OJS/OMP exchange and research modules. A DOCX from EuroOffice can be imported deliberately into Studio. No automatic bidirectional synchronization or embedded editor is claimed.

Read the [Studio and EuroOffice architecture guide](/docs/studio/office-separation).
