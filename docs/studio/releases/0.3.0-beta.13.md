# Open Manuscript Studio 0.3.0-beta.13

**Prepared 31 October 2026. This is a staged release document, not an announcement that beta.13 has been published.** The current downloads and app stores must remain on the last actually published version until the new release is built, verified and approved.

## Nine-stage stabilization

The Studio development PRs #786 and #788–#795 have been merged. The beta.13 source candidate consolidates improvements in structured manuscript identities and notes, history/validation, citations and bibliography, OMI file/container integrity, collaboration/review privacy, nested publication output, import/export diagnostics and conservative conformance/plugin/API capabilities.

- Import/export now checks ZIP/OMI JSON envelope validity and keeps the original document and editable candidate separate.
- Publishing preserves more nested sections, content, links and media for HTML/JATS pipelines.
- Draft capability reports cannot claim independent verification; the extension API manifest is strictly versioned and declarative.
- Author editing and deletion remain permitted; embedded provenance must not secretly lock text.

These are improvements to the Studio reference implementation, **not independent certification** and not a change of any OMI-SPEC Draft lifecycle.

## Required checks before publishing

Before merging the Studio release PR and updating the website's current-version labels, confirm all mandatory CI/CodeQL/native builds on the final merged commit, real long-DOCX/ODT/OMI reimport and export, editable text and note/citation fidelity, publishing/peer-review privacy, and Windows/Android upgrade with local data preserved.

Security hardening issues [#765](https://github.com/open-manuscript-initiative/open-manuscript-studio/issues/765) (egress), [#770](https://github.com/open-manuscript-initiative/open-manuscript-studio/issues/770) (Tauri CSP), [#774](https://github.com/open-manuscript-initiative/open-manuscript-studio/issues/774) (PDF worker isolation) and [#271](https://github.com/open-manuscript-initiative/open-manuscript-studio/issues/271) (upstream glib) remain release risk decisions and must not be described as fixed without evidence. Public distribution requires explicit owner Go/No-Go and signed artifacts.
