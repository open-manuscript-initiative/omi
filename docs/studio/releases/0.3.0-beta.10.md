# Open Manuscript Studio 0.3.0-beta.10

Release preparation: **24 October 2026**. This release keeps the live publication editor responsive while long manuscripts are paginated. Published historical releases remain immutable.

## What changes for users

- **Long-document pagination:** print-layout measurement of manuscript blocks and footnotes runs in short, cancellable animation-frame chunks, so the interface can respond between measurement batches.
- **Portable format:** the OMI manuscript format remains `OMI-SPEC-320@0.3.0`.

The OMI file format does not change in this beta.

## Updating and deployment

The [Studio downloads page](/studio/) follows the current published GitHub release. After the release PR is merged, native build workflows produce packages from the merged commit. Google Play requires a separate Android Release run from the merged `main`; its versionCode is derived from that run. iOS public distribution still requires Apple signing, provisioning and device/TestFlight validation.

No server migration is required.
