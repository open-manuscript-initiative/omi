# Studio 1.0.0-rc.3 — source candidate

**Source preparation: 23 November 2026.** [Release preparation PR #972](https://github.com/open-manuscript-initiative/open-manuscript-studio/pull/972) prepares an exact-version build with the merged [EuroOffice separation PR #971](https://github.com/open-manuscript-initiative/open-manuscript-studio/pull/971). **This is not yet a verified public prerelease or a Store update.** The RC1/RC2 physical-device and signing attestations are not automatically valid for RC3 binaries.

## Included in source

The embedded general-purpose EuroOffice editor and API bridge are removed. Studio retains its native DOCX/ODT import/export, scholarly text editing, footnotes, publication layouts, and OJS/OMP workflows. EuroOffice is operated separately. See the [architecture guide](/docs/studio/office-separation).
