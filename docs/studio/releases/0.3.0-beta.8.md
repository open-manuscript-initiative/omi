# Open Manuscript Studio 0.3.0-beta.8

Release preparation: **20 October 2026**. This release includes the merged DOCX title-import correction. Published historical releases remain immutable.

## What changes for users

- **DOCX import:** when the document title is repeated as the first numbered heading, Studio recognizes the duplicate in both standard and large-document imports so it is not displayed twice.
- **Portable format:** the OMI manuscript format remains `OMI-SPEC-320@0.3.0`.

## Application versions

| Platform or contract | Version |
|---|---|
| Shared Studio / web / native app version | `0.3.0-beta.8` |
| Windows MSI product version | `0.3.0.8` |
| iOS / iPadOS short version | `0.3.0` |
| iOS / iPadOS build | `20` |
| Android checked-in versionCode floor | `1207` |
| Portable OMI format | `OMI-SPEC-320@0.3.0` |

The OMI file format does not change in this beta.

## Updating and deployment

The [Studio downloads page](/studio/) follows the current published GitHub release. After the release PR is merged, native build and verified promotion workflows must finish before the new packages appear there. Google Play requires a separate new Android Release run from the merged `main`; its versionCode is derived from that run. iOS public distribution still requires Apple signing/provisioning and device/TestFlight validation.

No server migration is required for this client-side DOCX import correction. See the [technical release notes](https://github.com/open-manuscript-initiative/open-manuscript-studio/blob/main/docs/release/0.3.0-beta.8.md).
