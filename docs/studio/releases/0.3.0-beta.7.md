# Open Manuscript Studio 0.3.0-beta.7

Release preparation: **20 October 2026**. This beta collects the updates merged
since 0.3.0-beta.6 into new web, desktop and Android builds and updates iOS package
metadata. Published historical releases remain immutable.

## What changes for users

- **Android and EuroOffice:** the embedded editor and its lower controls stay
  inside the usable screen above system navigation. Compact floating controls
  leave more room for the document.
- **EuroOffice recovery:** standalone office documents retain recoverable save
  snapshots. Final saves are tied to the revision opened for editing; duplicate
  or late callbacks cannot overwrite a newer document revision.
- **Transkribus:** browse public recognition models by name, language or creator.
  Recognize one page image after explicitly approving the credit use, review and
  correct the result, then insert it with source and rights metadata. A suitable
  personal Transkribus account is required. Unknown paid requests are not
  automatically submitted again.
- **ODT — Preview:** import/export supported headings, formatting, lists, tables,
  notes and images. The importer checks archive limits, and export reports source
  relationships that ODT cannot preserve. Retain the OMI file for the complete
  source graph and manuscript history.
- **Translations and layout:** PO-backed interface labels and production loading
  of research-module translations are corrected. Desktop settings, language
  choices and document menus use compact responsive layouts.
- **Accounts and editors:** browser passkey authentication is available where
  configured; native passkey handoff remains unsupported. The redundant simple
  text editor is removed; OMI, visual publication and EuroOffice remain available.

## Updating and deployment

The [Studio downloads page](/studio/) follows the current published GitHub
release. After the release PR is merged, the native build and verified promotion
workflows must finish before the new installers/APK appear there. Google Play
requires a separate **new Android Release** run from the merged `main`, with
`publish_to_play: true` and the intended testing track; its versionCode is derived
from that run. Re-running an already uploaded run does not create a new Play
version. iOS public distribution still requires Apple signing/provisioning and
device/TestFlight validation.

Server operators must back up both databases, close active EuroOffice sessions,
apply pending application **and identity** migrations, and deploy the API before
the clients. Reopen EuroOffice documents after deployment. The
[technical release notes](https://github.com/open-manuscript-initiative/open-manuscript-studio/blob/main/docs/release/0.3.0-beta.7.md)
contain the commands and recovery/rollback guidance. See also the
[implementation status](/docs/governance/studio-implementation-status).
