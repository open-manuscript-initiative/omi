# Open Manuscript Studio 1.0.0-rc.1

**4 November 2026: Web Studio and the Android APK are available as 1.0.0-rc.1.**

- [Open Web Studio RC](https://studio.openmanuscript.org).
- [Download the Android RC package (ZIP)](https://github.com/open-manuscript-initiative/open-manuscript-studio/actions/runs/41741830930/artifacts/13282507414) from the verified build. GitHub sign-in may be required; extract the ZIP and install the APK inside it.
- Desktop download buttons continue to use the published [0.3.0-beta.13](https://github.com/open-manuscript-initiative/open-manuscript-studio/releases/tag/v0.3.0-beta.13) packages. Windows RC signing and full desktop acceptance are still pending.

The Android RC uses the **direct APK channel**. This does not announce an RC update on Google Play. A permanent all-platform GitHub `v1.0.0-rc.1` release is a separate publication step.

The [operator observations](https://github.com/open-manuscript-initiative/open-manuscript-studio/tree/a3ac0e98194c7d39a0013e280453c7f428d86dd0/docs/release/evidence/1.0.0-rc.1/e1200268ad549c0a40ace8724715cd2405e9d03c) record successful Windows/Android/web operation, OJS and OMP 3.5.0-5 connections, document recovery and responsive editing of a manuscript whose typeset PDF export has 46 pages. Windows keyboard access and Android label/button usability were also confirmed. The Android APK signature check succeeded according to the operator; Windows installers currently have no code signature.


## Changes in the candidate

- Unified continuous/frame publication layout, editable text/graphic frames,
  linked text flow, page styles, running headers and graphic placement.
- Table cell text rotation and direction, plus additional table editing controls.
- Visible validation progress, real check counts and per-check timing, with
  event-loop yields during long validations.
- PDF footnote and publication-fidelity work, media/package preservation,
  connection-pinned OJS/OMP/WebDAV requests and OIDC/JWKS hardening.
- RC publication stays opt-in. Immutable approved build bytes are reused, and
  an RC cannot silently become the general updater's latest stable release.

The portable manuscript format remains **OMI-SPEC-320@0.3.0**. Application
version 1.0 does not promote specification Drafts or certify independent conformance.

## Linux operator test — 4 November 2026

The operator reports that Linux testing started on **4 November 2026 at 11:53 CET** (`2026-11-04T10:53:00Z`) and that **everything works**. This supersedes the earlier lack of a Linux test environment. The time marks the start of testing; no completion time, distribution/version, package format or additional artifact digest was supplied. Linux remains Preview, including the inherited GLib limitation.

## Desktop publication and stable 1.0

Web/Android RC availability does not approve all desktop targets or the later stable `v1.0.0`. The full publication receipt remains partial. Outstanding work includes recording Linux package/environment details, Windows signing, application-plus-compatible-state recovery and the remaining exact-candidate host/integration acceptance. Successful functional observations remain in the operator record.

Follow the [final acceptance procedure](https://github.com/open-manuscript-initiative/open-manuscript-studio/blob/e1200268ad549c0a40ace8724715cd2405e9d03c/docs/release/2026-11-04-rc1-final-acceptance.md) for broader publication. Stable `v1.0.0` remains a later decision after RC observation.

Current acceptance policy (2026-11-07): the v1 receipt requires 14 manual gates including `ojs-3.5.0-6`. The observations and CI runs above remain historical for their original versions/commits; they do not supply acceptance for the expanded scope.
