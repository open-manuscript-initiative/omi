# Open Manuscript Studio 1.0.0-rc.1

## Microsoft Store update — 10 November 2026

According to Microsoft notifications forwarded by the publisher, the **Open Manuscript Studio Microsoft Store submission has been processed and the app is available in the Store**. Microsoft notes that storefront visibility can take up to two hours. The separate IARC notification confirms the ratings generated from the questionnaire submitted on 9 November are live; the supplied notice does not identify an individual age rating.

The publisher additionally supplied a **10 November Microsoft Store screenshot** showing the Open Manuscript Studio product page in Hungarian on Windows, including a **"Megnyitás" (Open)** button and **PEGI 3** rating. This independently supports listing visibility and Store recognition of an installation on that device; it does not establish successful app launch, Authenticode signature validation or update behavior. The exact Store product link was not supplied.

**Operator acceptance update, 10 November 2026:** The publisher separately confirmed successfully installing Open Manuscript Studio **directly from Microsoft Store** on their Windows device. The publisher subsequently confirmed that the Store-installed app **launches successfully and accepts account sign-in** on that Windows device. The publisher subsequently tested an existing local **`.omi` manuscript** end-to-end in the Store-installed Windows app: **open → edit → save → close/reopen**, and reported that all steps worked without errors. Package-signature verification and Store-managed upgrades (including preservation of data across an update) are still unverified.

This is a **Store-channel distribution milestone, not a stable Studio 1.0 approval**. The exact public listing URL, delivered package version, signature verification, Store-managed updates and data preservation remain to be recorded. The direct EXE/MSI download packages have not gained signatures through the Store. The 8 November MSIX packaging and pending-certification notes below are the historical status **as of 8 November** and do not supersede this update.

**4 November 2026: Web Studio and the Android APK are available as 1.0.0-rc.1.**

- [Open Web Studio RC](https://studio.openmanuscript.org).
- [Download the Android RC package (ZIP)](https://github.com/open-manuscript-initiative/open-manuscript-studio/actions/runs/41741830930/artifacts/13282507414) from the verified build. GitHub sign-in may be required; extract the ZIP and install the APK inside it.
- Desktop download buttons continue to use the published [0.3.0-beta.13](https://github.com/open-manuscript-initiative/open-manuscript-studio/releases/tag/v0.3.0-beta.13) packages. Store MSIX distribution was confirmed to the publisher on 10 November; direct Windows EXE/MSI signing and full desktop acceptance remain pending.

The Android RC uses the **direct APK channel**. This does not announce an RC update on Google Play. A permanent all-platform GitHub `v1.0.0-rc.1` release is a separate publication step.

The [operator observations](https://github.com/open-manuscript-initiative/open-manuscript-studio/tree/a3ac0e98194c7d39a0013e280453c7f428d86dd0/docs/release/evidence/1.0.0-rc.1/e1200268ad549c0a40ace8724715cd2405e9d03c) record successful Windows/Android/web operation, OJS and OMP 3.5.0-5 connections, document recovery and responsive editing of a manuscript whose typeset PDF export has 46 pages. Windows keyboard access and Android label/button usability were also confirmed. The Android APK signature check succeeded according to the operator; Windows installers currently have no code signature.

## Changes in the candidate

- Unified continuous/frame publication layout, editable text/graphic frames,
  linked text flow, page styles, running headers and graphic placement.
- Table cell text rotation and direction, plus additional table editing controls.
- Visible validation progress, real check counts and per-check timing, with
  event-loop yields during long validations.
- PDF footnote and publication-fidelity work, media/package preservation,
  connection-pinned OJS/OMP/WebDAV requests and OIDC/JWKS hardening.
- RC publication stays opt-in. Immutable approved build bytes are reused, and
  an RC cannot silently become the general updater's latest stable release.

The portable manuscript format remains **OMI-SPEC-320@0.3.0**. Application
version 1.0 does not promote specification Drafts or certify independent conformance.

Outstanding work includes recording Linux package/environment details, Windows signing, application-plus-compatible-state recovery and the remaining exact-candidate host/integration acceptance.
