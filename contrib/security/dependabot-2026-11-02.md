## Exposure and follow-up

The checked-in `deploy.sh` builds Docusaurus and copies the generated `build/`
directory into the web root. It does not run the Docusaurus preview server in
production. Confirm that hosting continues to serve those static files; do not
expose `docusaurus serve` or a development server as the public website.

The remaining minimatch path belongs to the preview server. Its advisory covers
all versions below 11.0.1, although the published amplification explanation
specifically describes a newer preprocessing implementation. This review does
not dismiss the alert based on that discrepancy.

The remaining deepmerge path is used by the SVG build transform. Treat imported
build configuration and SVG-transform options as trusted project code. The
upstream report demonstrates poisoning of the returned object's prototype;
the absence of global Object.prototype pollution is not proof of safety.

Recheck the upstream serve-handler/minimatch and SVGR/deepmerge chains before
the next dependency refresh. Close these alerts only after compatible upstream
fixes, verified dependency removal, or a separately reviewed mitigation.
