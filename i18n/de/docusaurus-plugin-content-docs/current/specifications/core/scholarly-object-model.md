# OMI-SPEC-120 — Wissenschaftliches Objektmodell

Informative deutsche Zusammenfassung von **OMI-SPEC-120 0.3.0 Draft**. Der englische Text ist maßgeblich; diese Seite ist keine vollständige normative Übersetzung.

Die Überarbeitung führt nummerierte, nachvollziehbare Anforderungen ein. Semantischer Inhalt, Objektidentität, Struktur und Metadaten bleiben von Darstellung und lokalen Berechtigungen getrennt. Quellenangaben und Prüfungen dürfen normale Autoreninhalte nicht unlöschbar machen.

Das gemeinsame Prüfprofil erfasst 66 Anforderungen und 22 geprüfte Beispiele. Für 20 Anforderungen liegen Teilnachweise vor; 46 sind noch ungeprüft. Dies bedeutet weder vollständige Konformität noch Stable-Status.
