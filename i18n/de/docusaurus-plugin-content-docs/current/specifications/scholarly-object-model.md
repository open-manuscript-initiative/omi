# Wissenschaftliches Objektmodell – Legacy-Route

:::Warnung: Ersetztes Dokument

Auf dieser Seite war zuvor die vorläufige Fassung von **OMI-SPEC-009: Scholarly Object Model** zu finden.

Diese vorläufige Kennung und das Duplikat-Dokument wurden außer Kraft gesetzt. Die kanonische Spezifikation lautet nun:

**[OMI-SPEC-120 — Scholarly Object Model](./core/scholarly-object-model.md)**

:::

## Migrationsstatus

In dem früheren Dokument wurden wissenschaftliche Objekte als identifizierbare, versionierte, erweiterbare semantische Entitäten beschrieben, die über Metadaten, Beziehungen, einen Lebenszyklus, eine Zusammensetzung, Verweise, Verhaltensweisen, Zugriffsrechte und eine Serialisierung verfügen.

Diese Konzepte sind in der kanonischen Spezifikation „OMI-SPEC-120“ dargestellt, die das maßgebliche und umfassendere Modell liefert. Der doppelte Text wird nicht mehr eigenständig gepflegt.

## Migration von Identifikatoren

| Vorherige vorläufige Kennung | Kanonische Kennung |
|---|---|
| `OMI-SPEC-009` | `OMI-SPEC-120` |

Neue Spezifikationen, Schemata, Beispiele und Implementierungen MÜSSEN auf `OMI-SPEC-120` verweisen.

Diese alte Route bleibt weiterhin verfügbar, um zu verhindern, dass es während der Überarbeitung der Dokumentation zu unbemerkten Verlinkungsfehlern kommt.
