# Datenschutzerklärung

Open Manuscript Studio ist so konzipiert, dass der Nutzer die volle Kontrolle über die Bearbeitung seiner Manuskripte behält. Dank der lokalen Bearbeitung und Speicherung der Manuskripte müssen diese nicht an einen externen Dienst übertragen werden.

Eine Netzwerkkommunikation findet statt, wenn der Benutzer bewusst eine netzwerkgestützte Funktion nutzt, beispielsweise die Anmeldung bei einem Studio-Server, die Synchronisierung oder das Öffnen von Remote-Inhalten, die Verbindung zu einer Installation unter OJS/OMP, die Nutzung von ORCID oder eines anderen konfigurierten Identitätsanbieters, die Nutzung eines konfigurierten Cloud-Speicher- bzw. Integrationsanbieters oder die Anforderung eines anderen von der Installation angebotenen Online-Dienstes.

Das Studio darf keine Inhalte von Manuskripten an unbeteiligte Dritte weitergeben, nur weil die Anwendung installiert oder geöffnet ist. Eine netzwerkgestützte Funktion kann die Daten übertragen, die für die Bereitstellung dieser Funktion technisch erforderlich sind, und der Betreiber des verbundenen Dienstes kann über eigene Datenschutzrichtlinien und Nutzungsbedingungen verfügen.

Die offiziellen Workflows für die Veröffentlichung und die Codesignierung verarbeiten Anwendungsbinärdateien und technische Build-Metadaten. Sie dürfen keine Benutzermanuskripte, Benutzeranmeldedaten, Inhalte der Produktionsdatenbank oder andere private Benutzerdaten enthalten.

Open Manuscript Studio ist Open Source. Benutzer und Administratoren können den Quellcode und die Bereitstellungskonfiguration einsehen, um festzustellen, welche Netzwerkdienste für eine bestimmte Installation aktiviert sind.

Fragen zum Datenschutz bei einer bestimmten gehosteten Installation sind an den Betreiber dieser Installation zu richten. Sicherheitsrelevante Probleme in der Software „Open Manuscript Initiative“ sind gemäß der Richtlinie „SECURITY.md“ des Projekts zu melden.
