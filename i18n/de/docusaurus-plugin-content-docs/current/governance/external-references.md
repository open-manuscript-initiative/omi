# Externe Referenzen und Wiederverwendung von Quellcode

Hier dokumentieren wir überprüfbare Verweise auf OMI und seine Software bei unabhängigen Diensten. Die Aufnahme in einen externen Katalog bedeutet für sich genommen weder eine unabhängige Qualitätszertifizierung noch eine Empfehlung oder Partnerschaft.

## XERJ Corpus Hub — ausgewählter Quellcode

Am **14. Oktober 2026** nahm der [XERJ Corpus Hub](https://hub.xerj.org/contributors/vargaijanos) **Varga István** als Mitwirkenden auf. Ein Beitrag zum [Open Manuscript Studio](https://github.com/open-manuscript-initiative/open-manuscript-studio) wurde für den Referenzkorpus ausgewählt. XERJ stellt KI-Programmieragenten durchsuchbare Implementierungsbeispiele mit Verweis auf das ursprüngliche Repository und die Urheber zur Verfügung.

Die Auswahl bezieht sich auf den Commit **„Preserve conditional UI while localizing labels“** ([369de7305b](https://github.com/open-manuscript-initiative/open-manuscript-studio/commit/369de7305becf512603fa3484254d5f26ad2f24c)): **9 Dateien**, **206 geänderte Zeilen**, TypeScript. Der Korpus indiziert das gesamte Repository am festgelegten Commit, nicht nur die geänderten Dateien.

Laut XERJ erfolgte die Aufnahme mit Einverständnis des Mitwirkenden; die Prüfung der MIT-Lizenz wurde abgeschlossen. Es handelt sich um eine **Aufnahme in einen Referenzkorpus**, nicht um eine Produktzertifizierung durch XERJ oder eine Partnerschaft mit OMI.
