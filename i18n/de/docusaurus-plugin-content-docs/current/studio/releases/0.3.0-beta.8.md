# Open Manuscript Studio 0.3.0-beta.8

Release-Vorbereitung: **20. Oktober 2026**. Dieses Release enthält die zusammengeführte Korrektur für doppelte Titel beim Word-Import. Bereits veröffentlichte Releases bleiben unverändert.

## Änderungen für Anwender

- **DOCX-Import:** Wenn der Dokumenttitel zugleich als erste nummerierte Überschrift erscheint, erkennt Studio diese Wiederholung sowohl beim normalen als auch beim Import großer Dokumente und zeigt den Titel nicht doppelt an.
- **Portables Format:** Das OMI-Manuskriptformat bleibt bei `OMI-SPEC-320@0.3.0`.

## Anwendungsversionen

| Plattform oder Format | Version |
|---|---|
| Gemeinsame Studio-/Web-/native Anwendungsversion | `0.3.0-beta.8` |
| Windows-MSI-Produktversion | `0.3.0.8` |
| iOS-/iPadOS-Kurzversion | `0.3.0` |
| iOS-/iPadOS-Build | `20` |
| Im Quellcode festgelegter Android-versionCode-Mindestwert | `1207` |
| Portables OMI-Format | `OMI-SPEC-320@0.3.0` |

Das OMI-Dateiformat ändert sich in dieser Beta nicht.

## Aktualisierung und Bereitstellung

Die [Studio-Downloadseite](/studio/) folgt dem aktuell veröffentlichten GitHub-Release. Nach dem Zusammenführen des Release-PR erscheinen neue Pakete nach Abschluss der nativen Builds und der verifizierten Veröffentlichung. Google Play benötigt einen neuen Android-Release-Lauf vom zusammengeführten `main`; der versionCode wird aus diesem Lauf abgeleitet. Die öffentliche iOS-Verteilung erfordert weiterhin Apple-Signierung/Provisioning und Geräte-/TestFlight-Validierung.

Für diese clientseitige DOCX-Importkorrektur ist keine Servermigration erforderlich. Siehe die [technischen Versionshinweise](https://github.com/open-manuscript-initiative/open-manuscript-studio/blob/main/docs/release/0.3.0-beta.8.md).
