# Studio 1.0.0-rc.3 — Quellcodekandidat

**Vorbereitung: 23. November 2026.** [Release-PR #972](https://github.com/open-manuscript-initiative/open-manuscript-studio/pull/972) bereitet neue Pakete mit der zusammengeführten [EuroOffice-Trennung #971](https://github.com/open-manuscript-initiative/open-manuscript-studio/pull/971) vor. **Dies ist noch keine bestätigte öffentliche GitHub-Vorabversion oder Store-Aktualisierung.** Gerätetests und Signaturfreigaben älterer Builds gelten nicht automatisch für RC3.

## Umfang

Der eingebettete EuroOffice-Editor und seine Studio-API-Routen wurden entfernt. Studio behält DOCX/ODT-Import und -Export, wissenschaftliches Schreiben, Anmerkungen, Publikationssatz und OJS/OMP-Arbeitsabläufe. EuroOffice wird unabhängig betrieben. Siehe [Architektur](/docs/studio/office-separation).

## Versionskanäle

| Kanal | Status |

| Portables Format | `OMI-SPEC-320@0.3.0` |

Der direkte Android-APK-VersionCode beträgt mindestens **1395**, während das signierte Play-AAB **1205 + Workflow-Laufnummer** verwendet. iOS experimentell: Build **28**, Marketing-Version **1.0.0**.

Die unveränderliche GitHub-Vorabversion `v1.0.0-rc.3` erfordert denselben Quell-SHA für native Builds, signierte Artefakte, geprüfte Prüfsummen, E02-Nachweise, vierzehn manuelle Gates und abschließendes Go/No-Go des Eigentümers. **Download-Links erst nach Paketprüfung ändern.**
