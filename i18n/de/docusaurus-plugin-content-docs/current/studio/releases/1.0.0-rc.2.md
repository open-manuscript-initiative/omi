# Open Manuscript Studio 1.0.0-rc.2 — aktuelle Kanäle

Stand: **20. November 2026**. Studio-Quellcode und gehostete Webanwendung verwenden **1.0.0-rc.2**. Die CI/CD-Pipeline für den genauen Quellstand hat die Produktionsbereitstellung erfolgreich abgeschlossen. Das [Entwicklungsupdate](/docs/studio/updates/2026-11-20) beschreibt die neuen Satz-, Anmerkungs-, Forschungsprojekt- und OJS-Funktionen.
