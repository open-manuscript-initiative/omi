# Studio RC4 — Release-Vorbereitung

Die Entwicklungen sind im Studio-Quellcode integriert. Die RC4-Versionsvorbereitung ist ein separater Pull Request; Version oder Paket-Upload belegen keine Bereitstellung. [PR #1044](https://github.com/open-manuscript-initiative/open-manuscript-studio/pull/1044).

**1.0.0-rc.4** · 2026-11-25

Der integrierte Quellcode enthält erweiterte Word-Interoperabilität, direktes Einfügen von Anmerkungen, formatierte Vorschauen und adaptive Speicherverwaltung. Die RC4-Versionsvorbereitung wird geprüft; Vertriebskanäle werden getrennt verifiziert.

Vorbereitete Paketkennungen, keine veröffentlichten Binärdateien: Windows MSI/MSIX 1.0.3.0; Android direkter versionCode 1600, signierter Workflow 1600 + Laufnummer; iOS Marketing 1.0.0, Build 29. Der zuvor dokumentierte Web/Android RC2 (1.0.0-rc.2), dauerhafte Desktop-Downloads 0.3.0-beta.13 und zuletzt bestätigter Store 1.0.0.0 bleiben getrennt. Prüfungen für den exakten SHA, signierte Artefakte und Freigabe sind erforderlich.
