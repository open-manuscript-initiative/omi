# Open Manuscript Studio 0.3.0-beta.11

Release-Vorbereitung: **24. Oktober 2026**. Diese Version verbessert die Reaktionsfähigkeit bei der Bearbeitung langer Dokumente und reduziert beim Navigieren die Darstellung außerhalb des sichtbaren Bereichs liegender Seitenführungen. Frühere veröffentlichte Versionen bleiben unverändert.

## Änderungen für Nutzerinnen und Nutzer

- **Live-Publikationseditor:** Zeilenmessungen unveränderter Blöcke werden wiederverwendet; nur von Bearbeitungen betroffene Inhalte werden erneut gemessen.
- **Navigation in der Druckansicht:** Seitenführungen werden für den sichtbaren Bereich und einen kleinen angrenzenden Puffer gerendert. Dadurch müssen bei sehr langen Manuskripten weniger dekorative Seitenelemente gezeichnet werden.
- **Portables Format:** Das OMI-Manuskriptformat bleibt `OMI-SPEC-320@0.3.0`.

## Aktualisierung und Bereitstellung

Die [Studio-Downloadseite](/studio/) verweist auf die aktuell veröffentlichte GitHub-Version. Nach dem Merge des Release-PRs erstellen die nativen Build-Workflows die Pakete aus dem zusammengeführten Commit. Für Google Play ist weiterhin ein separater Android-Release-Lauf vom zusammengeführten Branch `main` erforderlich; dieser bestimmt den versionCode. Für eine öffentliche iOS-Verteilung sind weiterhin die Apple-Signierung, die Bereitstellung und Tests auf Geräten oder über TestFlight erforderlich.

Eine Servermigration ist nicht erforderlich.
