# Studio RC5 — geplante OJS-Ausgaben

**1.0.0-rc.5** · 2026-11-26 · Integrierter Quellcode, kein bestätigtes öffentliches Release.

[Studio PR #1089](https://github.com/open-manuscript-initiative/open-manuscript-studio/pull/1089) · [Merged #1088](https://github.com/open-manuscript-initiative/open-manuscript-studio/pull/1088) · [OJS plugin 1.9.1 / #50](https://github.com/open-manuscript-initiative/omi-ojs-plugin/pull/50)

Vollständiger Import geplanter OJS-Ausgaben mit geordneten Artikeln, Anmerkungen, Fortschritt und nichtdestruktivem Reimport. Geprüfte physische PDF-Seitenbereiche, Artikel-PDF/HTML/JATS Article Authoring XML, bestätigte zielgebundene Dateiübertragung und separate Rückschreibung gedruckter Seitenzahlen. Artikel-DOI erfordert OJS-Plugin 1.9.1. Keine automatische Veröffentlichung, JATS Publishing-Zertifizierung oder PDF-XMP-Zusage.

Windows MSI/MSIX: 1.0.4.0 · Android versionCode: 2000 (+ workflow run number) · iOS: 1.0.0 / 30 · OMI-SPEC-320@0.3.0

Kompatibles Studio-Frontend, API und isolierten PDF-Worker mit qpdf und Poppler gemeinsam bereitstellen. OJS sichern und nach nativen Prüfungen mit veröffentlichtem TAR.GZ aktualisieren. Kennungen, Anmerkungen, Seitenbereiche und Empfangsbestätigungen an unveröffentlichter Ausgabe prüfen. Praxisabnahme und Release-Freigabe stehen aus. Store-Zähler prüfen.

## Aktueller Quellstand – 27. November 2026

RC5 ist integriert: vollständiger Import geplanter OJS-Ausgaben, beitragsbezogene Autorenbearbeitung, mehrsprachige Titelei-Felder und beitragsabhängige Kolumnentitel. Studio #1090 und #1091 sowie OJS #52 und #53 sind integriert. OJS main enthält 1.9.2.0; ein früheres Archiv derselben Version kann vor #53 erstellt worden sein. Paketprovenienz und Praxisabnahme prüfen.

Zuletzt bestätigte Referenzen: Web/Android 1.0.0-rc.2, Desktop 0.3.0-beta.13, Store 1.0.0.0; historische OJS v1.8.7 und OMP v1.5.1. Keine neu geprüften Live-Versionen.
