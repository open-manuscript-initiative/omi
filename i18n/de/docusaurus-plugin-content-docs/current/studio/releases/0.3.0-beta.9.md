# Open Manuscript Studio 0.3.0-beta.9

Release-Vorbereitung: **24. Oktober 2026**. Dieses Release enthält die zusammengeführte Korrektur für Linux-Deep-Links sowie niederländische und polnische Übersetzungen. Bereits veröffentlichte Releases bleiben unverändert.

## Änderungen für Anwender

- **Linux-Deep-Links:** Registrierung und Abfrage melden E/A-Fehler jetzt eindeutig. Beim Entfernen wird nur die MIME-Zuordnung dieser App gelöscht; Zuordnungen anderer Anwendungen bleiben erhalten.
- **Übersetzungen:** Enthalten sind die zurückgegebenen niederländischen und polnischen Übersetzungen für die gemeinsame Studio-Oberfläche und die Forschungsmodule.
- **Portables Format:** Das OMI-Manuskriptformat bleibt bei `OMI-SPEC-320@0.3.0`.

## Anwendungsversionen

| Plattform oder Format | Version |
|---|---|
| Gemeinsame Studio-/Web-/native Anwendungsversion | `0.3.0-beta.9` |
| Windows-MSI-Produktversion | `0.3.0.9` |
| iOS-/iPadOS-Kurzversion | `0.3.0` |
| iOS-/iPadOS-Build | `21` |
| Im Quellcode festgelegter Android-versionCode-Mindestwert | `1208` |
| Portables OMI-Format | `OMI-SPEC-320@0.3.0` |

Das OMI-Dateiformat ändert sich in dieser Beta nicht.

## Aktualisierung und Bereitstellung

Die [Studio-Downloadseite](/studio/) folgt dem aktuell veröffentlichten GitHub-Release. Nach dem Zusammenführen des Release-PR erstellen native Build-Workflows die Pakete aus dem zusammengeführten Commit. Google Play benötigt einen separaten Android-Release-Lauf vom zusammengeführten `main`; der versionCode wird aus diesem Lauf abgeleitet. Die öffentliche iOS-Verteilung erfordert weiterhin Apple-Signierung, Provisioning und Geräte-/TestFlight-Validierung.

Für dieses Release ist keine Servermigration erforderlich.
