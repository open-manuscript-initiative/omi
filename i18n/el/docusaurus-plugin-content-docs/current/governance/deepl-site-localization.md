# Ροή εργασιών για την τοπική προσαρμογή του ιστότοπου DeepL

Ο ιστότοπος OMI μπορεί να χρησιμοποιήσει το DeepL API για να συμπληρώσει τις ελλείπουσες μεταφράσεις της διεπαφής Docusaurus και της μεταφρασμένης τεκμηρίωσης, διατηρώντας παράλληλα την αγγλική πηγή ως την επίσημη.

## Ασφάλεια

Το κλειδί `API` δεν αποθηκεύεται ποτέ. Ορίστε το μόνο στο τρέχον shell:

```powershell
$env:DEEPL_API_KEY = "YOUR_KEY"
```

ή σε Linux/macOS:

```bash
export DEEPL_API_KEY="YOUR_KEY"
```

Τα σημεία τερματισμού των εκδόσεων DeepL Free και Pro αναγνωρίζονται από το κλειδί. Η διεύθυνση `DEEPL_API_URL` μπορεί να αντικαταστήσει το σημείο τερματισμού, όταν απαιτείται.

## Έλεγχος χωρίς χρήση του ορίου «API»

```bash
npm run i18n:deepl:site:check
```

Αυτή η αναφορά παρουσιάζει ποιες ρυθμισμένες γλώσσες υπάρχουν, πόσα αρχεία τεκμηρίωσης έχουν μεταφραστεί και ποια αρχεία πηγής εξακολουθούν να λείπουν. Δεν χρησιμοποιεί το DeepL και δεν τροποποιεί αρχεία.

## Μετάφραση των τοπικών ρυθμίσεων και των εγγράφων που λείπουν

```bash
npm run i18n:deepl:site
```

Για μια τοπική ρύθμιση που δεν υπάρχει ακόμα, το σενάριο εκτελεί πρώτα το Docusaurus `write-translations`, στη συνέχεια μεταφράζει τους πόρους που δημιουργήθηκαν στο JSON και δημιουργεί μεταφρασμένα αντίγραφα της αγγλικής τεκμηρίωσης στον τυπικό φάκελο i18n Docusaurus.

Τα υπάρχοντα αρχεία τεκμηρίωσης διατηρούνται. Οι γλώσσες Ουγγρικά και Γερμανικά αντιμετωπίζονται ως τοπικές ρυθμίσεις που συντηρούνται χειροκίνητα και δεν αναδημιουργούνται ποτέ με την εντολή ``--force``· μόνο τα αρχεία τεκμηρίωσης που λείπουν μπορούν να προστεθούν από την αγγλική πηγή.

## Επιλεγμένες τοποθεσίες

```bash
npm run i18n:deepl:site -- --locales=fr,es,it
```

## Εσκεμμένη αναδημιουργία τοπικών ρυθμίσεων που έχουν μεταφραστεί αυτόματα

```bash
npm run i18n:deepl:site -- --locales=fr --force
```

Κάντε το αυτό μόνο μετά από έλεγχο, καθώς αντικαθιστά τα υπάρχοντα, μεταφρασμένα αυτόματα αρχεία «JSON» και την τεκμηρίωση για την επιλεγμένη γλώσσα. Το περιεχόμενο στα ουγγρικά και στα γερμανικά που συντηρείται χειροκίνητα παραμένει προστατευμένο.

## Προστατευμένο περιεχόμενο

Ο μεταφραστής διατηρεί τα περικυκλωμένα τμήματα κώδικα και αποφεύγει να μεταφράζει τις εντολές import/export καθώς και τις δομικές γραμμές MDX. Ο ενσωματωμένος κώδικας, οι διευθύνσεις URL, οι προορισμοί συνδέσμων, οι θέσεις κράτησης προτύπων και η ορολογία του έργου, όπως OMI, OJS, OMP, ORCID, ROR, DOI, DOCX, IDML, JATS, CSL, CSS, HTML, PDF, WebAuthn και LaTeX, προστατεύονται από τη μηχανική μετάφραση.

## Επανεξέταση και επικύρωση

Η αυτόματη μετάφραση αποτελεί ένα πρώτο στάδιο και δεν έχει εγκριθεί από επιμελητή. Μετά τη δημιουργία:

1. να αναθεωρήσουν την ορολογία και τη γλώσσα των επιστημονικών εκδόσεων·
2. ελέγξτε την εμφάνιση και τους εσωτερικούς συνδέσμους στις διευθύνσεις Markdown/MDX·
3. εκτέλεση της εντολής «`npm run build`»;
4. να ελέγχετε τουλάχιστον την αρχική σελίδα, τη σελίδα «Studio» και αρκετές σελίδες τεκμηρίωσης σε κάθε νέα γλώσσα που δημιουργείται·
5. Να υποβάλλετε τα μεταφρασμένα αρχεία τοπικών ρυθμίσεων μόνο μετά από έλεγχο.

Η αγγλική τεκμηρίωση παραμένει η πηγή για τη μελλοντική δημιουργία αρχείων που λείπουν. Τα υπάρχοντα μεταφρασμένα αρχεία δεν αντικαθίστανται αυτόματα κατά τη διάρκεια των κανονικών εκτελέσεων.
