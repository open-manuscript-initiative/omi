# OMI Χάρτης αρχιτεκτονικής

**Κατάσταση:** Πρόχειρο

**Έκδοση:** 0.2

**Τελευταία ενημέρωση:** 5 Σεπτεμβρίου 2026
**Σταθερότητα:** Πειραματική  

---

## Περίληψη

Το Πρότυπο Ανοιχτού Κύκλου Ζωής Επιστημονικών Χειρογράφων (Open Manuscript Initiative) παρέχει μια ανοιχτή σημασιολογική αρχιτεκτονική για ολόκληρο τον κύκλο ζωής των επιστημονικών χειρογράφων.

OMI διαχωρίζει το επιστημονικό περιεχόμενο από το λογισμικό, την παρουσίαση, τη ροή εργασίας και την υποδομή του ιδρύματος. Οι προδιαγραφές του ορίζουν διαλειτουργικά μοντέλα για χειρόγραφα, επιστημονικά αντικείμενα, σημεία αναφοράς, σχολιασμούς, μεταδεδομένα, αξιολόγηση από ομοτίμους, έκδοση και επιστημονική εργασία με τη βοήθεια μηχανών.

Το παρόν έγγραφο παρουσιάζει τη γενική αρχιτεκτονική του OMI και περιγράφει τον τρόπο με τον οποίο συνδέονται μεταξύ τους οι βασικές προδιαγραφές και τα επίπεδα υλοποίησής του.

---

## 1. Αρχιτεκτονική επισκόπηση

Η αρχιτεκτονική του «OMI» χωρίζεται σε πέντε βασικά επίπεδα:

```text
┌─────────────────────────────────────────────────────────┐
│                 Application Layer                       │
│                                                         │
│       OMI Studio · Publisher Systems · OJS · Tools       │
├─────────────────────────────────────────────────────────┤
│                  Workflow Layer                         │
│                                                         │
│   Review · Collaboration · Versioning · Publishing      │
├─────────────────────────────────────────────────────────┤
│              Semantic Relationship Layer                │
│                                                         │
│       Anchors · Annotations · Citations · Provenance     │
├─────────────────────────────────────────────────────────┤
│                Scholarly Object Layer                   │
│                                                         │
│  Manuscript · Section · Paragraph · Figure · Table      │
│  Equation · Reference · Dataset · Supplementary Object  │
├─────────────────────────────────────────────────────────┤
│                  Foundation Layer                       │
│                                                         │
│        Core Principles · Identity · Portability         │
│        Extensibility · Preservation · Interoperability  │
└─────────────────────────────────────────────────────────┘
```

Κάθε στρώμα εξαρτάται από τα στρώματα που βρίσκονται από κάτω του.

Οι υλοποιήσεις των εφαρμογών μπορεί να διαφέρουν, αλλά τα σημασιολογικά μοντέλα παραμένουν σταθερά.

---

## 2. Βασική αρχιτεκτονική αρχή

OMI αντιμετωπίζει ένα χειρόγραφο όχι απλώς ως ένα μορφοποιημένο έγγραφο, αλλά ως ένα δομημένο γράφημα επιστημονικών αντικειμένων και σημασιολογικών σχέσεων.

```text
Scholarly Object
      │
      ├── has identity
      ├── has type
      ├── may contain other objects
      ├── may be targeted by anchors
      └── may participate in semantic relationships
```

Το χειρόγραφο, επομένως, αναπαρίσταται ως εξής:

```text
Objects + Relationships + Metadata + Provenance
```

Η παρουσίαση δημιουργείται με βάση αυτή την κανονική αναπαράσταση.

---

## 3. Το κανονικό χειρόγραφο

Το κανονικό χειρόγραφο περιέχει το έγκυρο επιστημονικό περιεχόμενο και τη δομή.

```text
Canonical Manuscript
│
├── Metadata
├── Contributors
├── Sections
│   ├── Headings
│   ├── Paragraphs
│   ├── Figures
│   ├── Tables
│   ├── Equations
│   └── Other scholarly objects
├── References
├── Notes
├── Annotations
├── Provenance
└── Workflow references
```

Το κανονικό χειρόγραφο είναι ανεξάρτητο από:

- μέγεθος σελίδας;
- τυπογραφία;
- πρότυπα εκδοτών·
- λογισμικό επεξεργασίας κειμένου·
- μορφή εξόδου;
- μηχανή απόδοσης·
- πλατφόρμα διαχείρισης εκδοτικού περιεχομένου.

PDF, HTML, DOCX, EPUB, JATS XML, καθώς και άλλες μορφές δημοσίευσης, αποτελούν παράγωγες αναπαραστάσεις.

## 4. Χάρτης εξαρτήσεων προδιαγραφών

Οι βασικές προδιαγραφές του OMI σχηματίζουν την ακόλουθη δομή εξαρτήσεων:

```text
OMI-SPEC-000
Core Principles
      │
      ▼
OMI-SPEC-120
Scholarly Object Model
      │
      ├──────────────────────────────┐
      ▼                              ▼
OMI-SPEC-100                   OMI-SPEC-140
Document Model                 Metadata Model
      │
      ▼
OMI-SPEC-110
Anchor Model
      │
      ▼
OMI-SPEC-130
Annotation Model
      │
      ├───────────────┬────────────────┬────────────────┐
      ▼               ▼                ▼                ▼
Review Model     Citation Model   AI Assistance    Publishing Model
```

Οι βασικές αρχές καθορίζουν τους αρχιτεκτονικούς περιορισμούς.

Το Μοντέλο Επιστημονικών Αντικειμένων καθορίζει τι μπορεί να υπάρχει στο οικοσύστημα του Δικτύου Επιστημονικών Αντικειμένων (OMI).

Το Μοντέλο Εγγράφων οργανώνει τα επιστημονικά αντικείμενα σε χειρόγραφα.

Το μοντέλο «Anchor» προσδιορίζει σταθερούς στόχους.

Το μοντέλο σχολιασμού καθορίζει τις σημασιολογικές σχέσεις που συνδέονται με αυτούς τους στόχους.

Οι προδιαγραφές για τη ροή εργασιών και τη διαλειτουργικότητα βασίζονται σε αυτά τα θεμέλια.

# 5. Στρώμα θεμελίωσης

## 5.1 Βασικές αρχές

**Το έγγραφο «OMI-SPEC-000 — Core Principles»** καθορίζει την αρχιτεκτονική δομή του OMI.

Οι βασικοί κανόνες του περιλαμβάνουν:

- το περιεχόμενο είναι το κανονικό·
- η σημασιολογία προηγείται της μορφοποίησης·
- τα επιστημονικά αντικείμενα διαθέτουν σταθερή ταυτότητα·
- οι σχέσεις είναι δεδομένα πρώτης τάξης·
- η παρουσίαση εξαρτάται από τον μηχανισμό απόδοσης·
- η ταυτότητα και το περιεχόμενο είναι ξεχωριστά ζητήματα·
- οι υλοποιήσεις παραμένουν ανεξάρτητες από τον προμηθευτή·
- Η διατήρηση αποτελεί πρωταρχικό στόχο του σχεδιασμού.

Κάθε προδιαγραφή του OMI ΠΡΕΠΕΙ να παραμένει σύμφωνη με αυτές τις αρχές.

---

## 5.2 Επιστημονικό μοντέλο αντικειμένων

**OMI-SPEC-120 — Μοντέλο Επιστημονικού Αντικειμένου** ορίζει την κοινή αφαίρεση που μοιράζονται όλες οι ουσιαστικές οντότητες.

Μερικά παραδείγματα είναι:

- χειρόγραφα·
- ενότητες·
- παράγραφοι·
- επικεφαλίδες;
- αριθμοί·
- πίνακες;
- εξισώσεις·
- παραπομπές·
- βιβλιογραφικές εγγραφές·
- σχόλια;
- κριτικές;
- σύνολα δεδομένων;
- συμπληρωματικό υλικό·
- συγγραφείς και συνεργάτες.

Ένα επιστημονικό αντικείμενο διαθέτει τουλάχιστον:

```json
{
  "id": "object-123",
  "type": "paragraph"
}
```

Οι επιπλέον ιδιότητες εξαρτώνται από τον τύπο του αντικειμένου.

# 6. Επίπεδο βασικού μοντέλου

## 6.1 Μοντέλο εγγράφου

**OMI-SPEC-100 — Μοντέλο εγγράφου** ορίζει τη δομική οργάνωση ενός χειρογράφου.

Περιγράφει:

- ιδιότητες σε επίπεδο χειρογράφου·
- ενότητες και ιεραρχική δομή·
- ενότητες περιεχομένου;
- ενσωματωμένο περιεχόμενο;
- αναφορές σε εξωτερικά επιστημονικά αντικείμενα·
- σχέσεις μεταξύ των στοιχείων ενός εγγράφου.

Το μοντέλο εγγράφου δεν καθορίζει την οπτική εμφάνιση.

---

## 6.2 Μοντέλο αγκύρωσης

**Το πρότυποOMI-SPEC-110 — Anchor Model** ορίζει σταθερές αναφορές σε επιστημονικά αντικείμενα ή σε επιλεγμένες περιοχές εντός αυτών.

Ένας σύνδεσμος μπορεί να παραπέμπει σε:

- ένα ολόκληρο χειρόγραφο·
- ένα τμήμα·
- μια παράγραφος·
- ένα τμήμα κειμένου εντός γραμμής·
- ένα σχήμα·
- μια περιοχή σχήματος·
- ένας πίνακας·
- ένα κελί πίνακα·
- μια εξίσωση·
- μια παραπομπή·
- μια βιβλιογραφική εγγραφή·
- μεταδεδομένα;
- μια εξωτερική πηγή.

```text
Anchor
  │
  ▼
Stable target within a scholarly object
```

Τα σημεία αναφοράς εξασφαλίζουν ότι οι σχολιασμοί και οι σχέσεις διατηρούνται κατά την επεξεργασία, την αναδιάρθρωση και την εκ νέου απόδοση.

---

## 6.3 Μοντέλο σχολιασμού

**OMI-SPEC-130 — Μοντέλο σχολιασμού** ορίζει τους σχολιασμούς ως επιστημονικά αντικείμενα πρώτης κατηγορίας.

```text
Annotation
    │
    ├── type
    ├── body
    ├── creator or actor reference
    ├── visibility
    ├── provenance
    └── target
            │
            ▼
          Anchor
```

Οι σχολιασμοί μπορεί να αφορούν:

- σημειώσεις;
- σχόλια;
- παρατηρήσεις από την αξιολόγηση από ομοτίμους·
- οδηγίες σύνταξης·
- σχέσεις παραπομπών·
- Προτάσεις τεχνητής νοημοσύνης·
- οδηγίες δημοσίευσης·
- σημασιολογικές ταξινομήσεις.

Μια σχολιασμένη σημείωση αποθηκεύεται ανεξάρτητα από το κείμενο στο οποίο αναφέρεται.

---

## 6.4 Μοντέλο μεταδεδομένων

**OMI-SPEC-140 — Μοντέλο μεταδεδομένων** ορίζει τα περιγραφικά, διοικητικά, τεχνικά και μεταδεδομένα διατήρησης.

Τα μεταδεδομένα μπορούν να περιγράφουν:

- τίτλος;
- γλώσσα;
- συγγραφική πατρότητα·
- συνδέσεις·
- αναγνωριστικά;
- θέματα·
- λέξεις-κλειδιά;
- χρηματοδότηση·
- δικαιώματα·
- κατάσταση δημοσίευσης;
- προέλευση·
- πληροφορίες σχετικά με συγκεκριμένα επιστημονικά πεδία.

Το μοντέλο μεταδεδομένων έχει σχεδιαστεί ώστε να είναι συμβατό με τα καθιερωμένα πρότυπα και συστήματα αναγνωριστικών.

# 7. Επίπεδο ροής εργασιών

## 7.1 Μοντέλο αναθεώρησης

**ΤοOMI-SPEC-200 — Review Model** ορίζει δομημένες ροές εργασιών για την αξιολόγηση από ομοτίμους.

Βασίζεται στο Μοντέλο Σχολιασμού.

```text
Review Annotation
      │
      ├── reviewer pseudonym
      ├── review round
      ├── recommendation
      ├── visibility policy
      ├── confidential or author-facing body
      └── target anchor
```

Το μοντέλο αξιολόγησης υποστηρίζει:

- ανοιχτή αξιολόγηση;
- αξιολόγηση από έναν μόνο ανώνυμο χρήστη·
- διπλά ανώνυμη αξιολόγηση·
- τριπλά ανώνυμη αξιολόγηση·
- εμπιστευτικά σχόλια του συντάκτη·
- σχόλια που απευθύνονται στον συγγραφέα·
- πολλαπλοί γύροι αξιολόγησης·
- δομημένες συστάσεις·
- να ελέγξουν τα αρχεία καταγραφής ελέγχου.

Η ταυτότητα του αξιολογητή διαχωρίζεται από το περιεχόμενο της αξιολόγησης που μπορεί να μεταφερθεί.

---

## 7.2 Μοντέλο συνεργασίας

**OMI-SPEC-210 — Collaboration Model** ορίζει τον τρόπο αλληλεπίδρασης μεταξύ πολλών χρηστών σε ένα χειρόγραφο.

Μπορεί να υποστηρίζει:

- συγγραφείς·
- συν-συγγραφείς·
- συντάκτες·
- μεταφραστές·
- κριτικοί·
- διορθωτές κειμένων·
- διορθωτές·
- τεχνικοί συνεργάτες·
- Βοηθοί τεχνητής νοημοσύνης.

Τα δικαιώματα συνεργασίας βασίζονται σε ρόλους και εξαρτώνται από το αντικείμενο.

---

## 7.3 Μοντέλο διαχείρισης εκδόσεων

**Το μοντέλο διαχείρισης εκδόσεων «OMI-SPEC-220»** καθορίζει την εξέλιξη ενός χειρογράφου.

```text
Version 1
    │
    ▼
Change Set
    │
    ▼
Version 2
```

Το μοντέλο θα πρέπει να υποστηρίζει:

- αμετάβλητοι αναγνωριστικοί έκδοσης·
- αλλαγές σε επίπεδο αντικειμένου·
- ιστορικό αναθεωρήσεων;
- διακλάδωση·
- συγχώνευση;
- προέλευση·
- σύγκριση μεταξύ εκδόσεων·
- στιγμιότυπα από τον γύρο αξιολόγησης.

---

## 7.4 Μοντέλο δημοσίευσης

**OMI-SPEC-230 — Μοντέλο δημοσίευσης** περιγράφει τη μετατροπή του κανονικού χειρογράφου σε δημοσιευμένα αποτελέσματα.

```text
Canonical OMI Manuscript
          │
          ▼
 Publisher Profile
          │
          ▼
 Rendering Pipeline
          │
          ├── HTML
          ├── PDF
          ├── DOCX
          ├── EPUB
          ├── JATS XML
          ├── LaTeX
          └── Future formats
```

Τα προφίλ εκδοτών μπορούν να ορίζουν:

- τυπογραφία;
- στυλ παραπομπής·
- τοποθέτηση σημειώσεων·
- ιεραρχία επικεφαλίδων·
- γεωμετρία σελίδας;
- επεξεργασία εικόνων·
- απαιτήσεις μεταδεδομένων·
- μετασχηματισμοί που αφορούν συγκεκριμένα τα αποτελέσματα.

Το κανονικό χειρόγραφο παραμένει αμετάβλητο.

## 8.1 Αρχιτεκτονική προσθηκών

**OMI-SPEC-300 — Αρχιτεκτονική προσθηκών** ορίζει τους μηχανισμούς επεκτασιμότητας.

- νέοι τύποι επιστημονικών αντικειμένων·
- μεταδεδομένα συγκεκριμένου επιστημονικού κλάδου·
- προγράμματα απόδοσης·
- εξαγωγείς και εισαγωγείς·

- ροές εργασίας σύνταξης·

- Υπηρεσίες τεχνητής νοημοσύνης.

Τα πρόσθετα ΔΕΝ ΠΡΕΠΕΙ να θέτουν σε κίνδυνο τη μεταφορά του κανονικού χειρογράφου.

## 8.2 Πλατφόρμα API

** Το έγγραφο «OMI-SPEC-310 — Platform API»** ορίζει τον τρόπο προγραμματιστικής αλληλεπίδρασης με τα χειρόγραφα και τα επιστημονικά αντικείμενα του OMI.

Το αρχείο «API» μπορεί να περιέχει:

- ανάκτηση χειρογράφων·
- δημιουργία και τροποποίηση αντικειμένων·
- λειτουργίες σχολιασμού·
- ανάλυση αγκύρωσης;
- επικύρωση;
- απόδοση;
- ενσωμάτωση ροών εργασίας·
- εισαγωγές και εξαγωγές·

## 8.3 Μορφή αρχείου

**Το πρότυπο «[OMI-SPEC-320 — File Format](../specifications/file-format.md)»** ορίζει τη φορητή λογική αναπαράσταση JSON ενός χειρογράφου OMI.

Το ίδιο λογικό έγγραφο μπορεί να μεταφερθεί ως αυτόνομο αρχείο τύπου «`.omi.json`» ή ως τμήμα χειρογράφου που έχει ανασυντεθεί από ένα κοντέινερ τύπου «OMI». Η μορφή αρχείου ορίζει την ταυτοποίηση, τη διαπραγμάτευση έκδοσης, την ανάλυση, τη σειριοποίηση, την επικύρωση, τις αναφορές, τις επεκτάσεις, την προαιρετική ανταλλαγή ιστορικού και τη μετεγκατάσταση, χωρίς να καθορίζει διαδρομές αρχειοθέτησης ή συμπίεση.

Η μορφή θα πρέπει να δίνει προτεραιότητα στα εξής:

- διαφάνεια·
- επικύρωση;
- δυνατότητα ανάκτησης·
- μακροπρόθεσμη συντήρηση·
- ανεξαρτησία υλοποίησης.

---

## 8.4 Αρχιτεκτονική κοντέινερ

**Το αρχείο[OMI-SPEC-330 — Container Architecture](../specifications/container-architecture.md)** καθορίζει τον τρόπο με τον οποίο τα σχετικά αρχεία συγκεντρώνονται σε ένα πακέτο `.omi` που μπορεί να ελεγχθεί.

Ένα δοχείο μπορεί να περιέχει:

```text
manuscript.omi
│
├── META-INF/
├── manuscript/
├── media/
├── profiles/
├── plugins/
└── publication/
```

Το κοντέινερ καθορίζει την αναγνώριση των τμημάτων, την ασφάλεια της διαδρομής, τη διαχείριση των μέσων, την ακεραιότητα, τις υπογραφές και τη συσκευασία διατήρησης, αφήνοντας τη σημασιολογία των χειρογράφων στο πρότυπο «OMI» (SPEC-320) και στα βασικά μοντέλα.

# 9. Επίπεδο τεχνητής νοημοσύνης

## 9.1 Υποστήριξη από τεχνητή νοημοσύνη

**OMI-SPEC-400 — Βοήθεια από τεχνητή νοημοσύνη** περιγράφει τον τρόπο με τον οποίο οι προτάσεις που δημιουργούνται από μηχανές αλληλεπιδρούν με τα επιστημονικά χειρόγραφα.

Τα αποτελέσματα της τεχνητής νοημοσύνης παρουσιάζονται ως περιεχόμενο που φέρει σχολιασμό ή πληροφορίες προέλευσης.

```text
AI Service
    │
    ▼
AI Annotation
    │
    ├── model or service identifier
    ├── creation time
    ├── operation type
    ├── confidence or rationale
    ├── target anchor
    └── human review status
```

Οι προτάσεις της τεχνητής νοημοσύνης δεν αντικαθιστούν αυτόματα το κανονικό περιεχόμενο.

---

## 9.2 Αξιολόγηση της τεχνητής νοημοσύνης

**Το έγγραφο «OMI-SPEC-410 — AI Review»** ορίζει την αξιολόγηση ποιότητας με τη βοήθεια μηχανών.

Μερικές από τις πιθανές λειτουργίες είναι:

- δομική επικύρωση·
- έλεγχος παραπομπών·
- συνέπεια στην ορολογία·
- γλωσσική ανάλυση·
- έλεγχος προσβασιμότητας·
- επικύρωση μεταδεδομένων·
- στατιστικές προειδοποιήσεις·
- συμμόρφωση με το προφίλ δημοσίευσης.

Η αξιολόγηση με τεχνητή νοημοσύνη εξακολουθεί να διακρίνεται από την ανθρώπινη αξιολόγηση από ομοτίμους.

---

## 9.3 Προέλευση

**OMI-SPEC-420 — Η «προέλευση»** καταγράφει τον τρόπο με τον οποίο δημιουργήθηκαν ή τροποποιήθηκαν τα επιστημονικά αντικείμενα.

Η προέλευση μπορεί να προσδιορίζει:

- άνθρωποι που συνέβαλαν·
- εργαλεία λογισμικού·
- πράξεις εισαγωγής·
- Συστήματα τεχνητής νοημοσύνης·
- διαδικασίες μετασχηματισμού·
- συστήματα έκδοσης·
- υπηρεσίες επικύρωσης.

Η προέλευση διασφαλίζει τη διαφάνεια χωρίς να απαιτείται η δημόσια αποκάλυψη όλων των στοιχείων ταυτότητας.

# 10. Επίπεδο εφαρμογών

## 10.1 OMI Studio

OMI Studio είναι ένα περιβάλλον δημιουργίας αναφορών που βασίζεται στις προδιαγραφές του Προτύπου Τεκμηρίωσης Προτύπων (OMI).

```text
OMI Studio
│
├── Manuscript editor
├── Scholarly object inspector
├── Annotation panel
├── Notes editor
├── Review interface
├── Metadata editor
├── Publisher preview
├── Validation
├── Import
└── Export
```

OMI Studio αποτελεί μια εφαρμογή των προδιαγραφών και όχι την ίδια την προδιαγραφή.

Άλλες εφαρμογές ενδέχεται να υλοποιούν την εντολή «OMI» με διαφορετικό τρόπο.

---

## 10.2 Συστήματα εκδοτών

Οι εκδότες και οι πλατφόρμες διαχείρισης περιοδικών μπορούν να χρησιμοποιούν το OMI για:

- λήψη υποβολών·
- τεχνική επικύρωση·
- αξιολόγηση από ομοτίμους·
- διόρθωση κειμένου;
- παραγωγή·
- δημοσίευση·
- κατάθεση σε αποθετήριο·
- μακροπρόθεσμη διατήρηση.

Ένας εκδότης μπορεί να εφαρμόσει το «OMI» απευθείας ή να το ενσωματώσει μέσω ενός «API» ή ενός plugin.

---

## 10.3 Εξωτερικά συστήματα

OMI έχει σχεδιαστεί για να συνεργάζεται με εξωτερικές ακαδημαϊκές υποδομές.

Μερικά παραδείγματα είναι:

```text
OMI
 │
 ├── OJS and journal management platforms
 ├── Institutional repositories
 ├── DOI registration services
 ├── ORCID
 ├── ROR
 ├── Crossref
 ├── DataCite
 ├── CSL
 ├── JATS
 ├── IIIF
 ├── Preservation systems
 └── Research data repositories
```

OMI δεν αποσκοπεί στην αντικατάσταση αυτών των υποδομών.

Παρέχει ένα φορητό σημασιολογικό επίπεδο χειρογράφου μεταξύ τους.

# 11. Αρχιτεκτονική ταυτότητας και προστασίας της ιδιωτικής ζωής

Η ταυτότητα αντιμετωπίζεται ξεχωριστά από το κανονικό επιστημονικό περιεχόμενο.

```text
Portable OMI Content
│
├── actor role
├── pseudonym
├── contribution type
└── public provenance
        │
        │ protected mapping
        ▼
Institutional Identity System
├── account
├── verified identity
├── permissions
└── confidential audit data
```

Αυτή η διαχωριστική γραμμή υποστηρίζει:

- ανώνυμη αξιολόγηση από ομοτίμους·
- συνεργασία με διαφύλαξη της ιδιωτικότητας·
- ελεγχόμενη αποκάλυψη ταυτότητας·
- θεσμική λογοδοσία·
- φορητά αρχεία ανασκόπησης.

Οι δεσμεύσεις ιδιωτικής ταυτότητας ΔΕΝ ΠΡΕΠΕΙ να περιλαμβάνονται σε μεταφερόμενα πακέτα ανώνυμης αξιολόγησης.

# 13. Παράδειγμα: κύκλος ζωής μιας σχολιασμένης εργασίας μετά από αξιολόγηση από ομοτίμους

Το παρακάτω παράδειγμα δείχνει πώς αλληλεπιδρούν τα διάφορα επίπεδα του μοντέλου «OMI».

```text
1. A paragraph exists as a scholarly object.
                    │
                    ▼
2. An anchor identifies a sentence in the paragraph.
                    │
                    ▼
3. A reviewer creates a review annotation.
                    │
                    ▼
4. The Review Model applies anonymity and visibility rules.
                    │
                    ▼
5. The author receives an anonymized review projection.
                    │
                    ▼
6. The author revises the canonical manuscript.
                    │
                    ▼
7. The Versioning Model records the change.
                    │
                    ▼
8. The annotation is resolved or retained as provenance.
```

Το σχόλιο της αναθεώρησης δεν ενσωματώνεται μόνιμα στην παράγραφο.

Παραμένει ένα ανεξάρτητο, ανιχνεύσιμο επιστημονικό αντικείμενο.

# 15. Αμετάβλητα στοιχεία αρχιτεκτονικής

Όλες οι συμμορφούμενες υλοποιήσεις του OMI ΠΡΕΠΕΙ να διατηρούν τις ακόλουθες σταθερές.

## 15.1 Αμετάβλητο κανονικού περιεχομένου

Οι αλλαγές που αφορούν αποκλειστικά την παρουσίαση ΔΕΝ ΠΡΕΠΕΙ να αλλοιώνουν την κανονική επιστημονική έννοια.

## 15.2 Αμετάβλητο σταθερής ταυτότητας

Ένα επιστημονικό αντικείμενο ΠΡΕΠΕΙ να διατηρεί την ταυτότητά του κατά τη διάρκεια των συνήθων εργασιών επεξεργασίας.

## 15.3 Αμετάβλητο σχέσης

Οι σημασιολογικές σχέσεις ΠΡΕΠΕΙ να παραμένουν ρητές και αναγνώσιμες από μηχανές.

## 15.4 Αμετάβλητο μεταφοράς

Ένα χειρόγραφο ΠΡΕΠΕΙ να παραμένει κατανοητό εκτός του λογισμικού με το οποίο δημιουργήθηκε.

## 15.5 Αμετάβλητη ιδιότητα απορρήτου

Οι εμπιστευτικές πληροφορίες ταυτότητας ΠΡΕΠΕΙ να παραμένουν διαχωρισμένες από το μεταβιβάσιμο επιστημονικό περιεχόμενο.

## 15.6 Αμετάβλητη προέλευση

Οι ουσιαστικές μετατροπές, τόσο οι αυτοματοποιημένες όσο και αυτές που γίνονται από τον άνθρωπο, ΠΡΕΠΕΙ να είναι προσδιορίσιμες ως προς την προέλευσή τους.

## 15.7 Αμετάβλητη επεκτασιμότητα

Οι προσθήκες ΠΡΕΠΕΙ να διατηρούν την εγκυρότητα και την αναγνωσιμότητα του αρχικού χειρογράφου.

# 16. Αρχιτεκτονικά όρια

OMI ορίζει:

- σημασιολογικές δομές χειρογράφων·
- ταυτότητες επιστημονικών αντικειμένων·
- άγκυρες;
- σχόλια;
- αναπαραστάσεις ροών εργασίας·
- διαλειτουργικά μεταδεδομένα·
- φορητές δομές συσκευασίας·
- εισόδους απόδοσης·
- μηχανισμοί επέκτασης.

OMI δεν ορίζει:

- ένας μόνο συντάκτης·
- μία ενιαία πλατφόρμα δημοσίευσης·
- μία μόνο βάση δεδομένων·
- μία μόνο γλώσσα προγραμματισμού·
- μία μόνο μέθοδος αξιολόγησης από ομοτίμους·
- ένα ενιαίο στυλ παραπομπών·
- ένα ενιαίο οπτικό σχέδιο·
- μία ενιαία θεσμική ροή εργασιών.

Οι υλοποιήσεις εξακολουθούν να έχουν την ελευθερία να επιλέγουν τις εσωτερικές τους τεχνολογίες.

# 18. Συμπέρασμα

Το Πρότυπο Διαχείρισης Αρχείων (Open Manuscript Initiative) παρέχει μια πολυεπίπεδη σημασιολογική αρχιτεκτονική και όχι μια μονολιθική μορφή αρχείου.

Η κεντρική του αφαιρετική έννοια είναι ο γράφος επιστημονικών αντικειμένων:

```text
Stable scholarly objects
        +
Explicit semantic relationships
        +
Portable metadata
        +
Traceable provenance
```

Οι εφαρμογές, οι ροές εργασίας και οι μορφές δημοσίευσης βασίζονται σε αυτόν τον γράφο.

Διαχωρίζοντας το επιστημονικό περιεχόμενο από την παρουσίαση και την υποδομή, το «OMI» επιτρέπει στα χειρόγραφα να μετακινούνται μεταξύ συγγραφέων, επιστημονικών κλάδων, εκδοτών, αποθετηρίων και μελλοντικών τεχνολογιών χωρίς να χάνουν την πνευματική τους δομή.
