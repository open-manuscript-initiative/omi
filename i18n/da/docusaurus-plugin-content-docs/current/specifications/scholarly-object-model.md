# Videnskabelig objektmodel — Den traditionelle metode

:::advarsel: Dokumentet er erstattet

Denne side indeholdt tidligere den foreløbige **OMI-SPEC-009: Scholarly Object Model**.

Den midlertidige identifikator og det duplikerede dokument er blevet udfaset. Den kanoniske specifikation er nu:

**[OMI-SPEC-120 — Scholarly Object Model](./core/scholarly-object-model.md)**

:::

## Indvandringsstatus

I det tidligere dokument blev videnskabelige objekter beskrevet som identificerbare, versionsstyrede og udvidelige semantiske enheder med metadata, relationer, livscyklus, sammensætning, referencer, adfærd, tilladelser og serialisering.

Disse begreber er beskrevet i den kanoniske specifikation »OMI« (SPEC-120), som udgør den autoritative og mere omfattende model. Den overlappende tekst vedligeholdes ikke længere separat.

## Overførsel af identifikatorer

| Forrige foreløbig identifikator | Kanonisk identifikator |
|---|---|
| `OMI-SPEC-009` | `OMI-SPEC-120` |

Nye specifikationer, skemaer, eksempler og implementeringer SKAL henvise til `OMI-SPEC-120`.

Denne ældre rute er fortsat tilgængelig for at forhindre, at links brydes uden varsel under omarbejdningen af dokumentationen.
