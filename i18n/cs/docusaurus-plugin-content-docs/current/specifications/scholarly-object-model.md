# Model vědeckých objektů — starší přístup

:::varování: Nahrazený dokument

Na této stránce byl dříve zveřejněn prozatímní dokument **OMI-SPEC-009: Scholarly Object Model**.

Tento prozatímní identifikátor a duplicitní dokument byly zrušeny. Kanonická specifikace nyní zní:

**[OMI-SPEC-120 — Scholarly Object Model](./core/scholarly-object-model.md)**

:::

## Migrační status

V předchozím dokumentu byly vědecké objekty popsány jako identifikovatelné, verzované a rozšiřitelné sémantické entity, které zahrnují metadata, vztahy, životní cyklus, složení, odkazy, chování, oprávnění a serializaci.

Tyto pojmy jsou popsány v kanonické specifikaci OMI-SPEC-120, která představuje autoritativní a ucelenější model. Duplikát tohoto textu již není samostatně aktualizován.

## Migrace identifikátorů

| Předchozí prozatímní identifikátor | Kánonický identifikátor |
|---|---|
| `OMI-SPEC-009` | `OMI-SPEC-120` |

Nové specifikace, schémata, příklady a implementace MUSÍ odkazovat na `OMI-SPEC-120`.

Tato starší trasa zůstává k dispozici, aby se zabránilo nepozorovanému přerušení spojení během programu refaktoringu dokumentace.
