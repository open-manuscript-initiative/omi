# Open Manuscript Initiative

Projekt „Open Manuscript Initiative“ (OMI) je komunitní projekt založený na open source, jehož cílem je zlepšování vědeckého publikování.

## Poslání

Naším posláním je poskytovat vysoce kvalitní dokumentaci, doplňky, integrace a osvědčené postupy pro platformy určené k publikování vědeckých prací.

## Podporované platformy

- Open Journal Systems (OJS)
- Open Monograph Press (OMP)
- Systémy otevřených preprintů (OPS)
- Janewayová
- DSpace
- Omeka
