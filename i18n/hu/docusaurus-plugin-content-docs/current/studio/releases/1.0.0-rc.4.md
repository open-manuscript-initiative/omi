# Stúdió RC4 — kiadás előkészítése

A fejlesztések bekerültek a Stúdió forráskódjába. Az RC4 verzióemelés beolvadt; a verziószám vagy csomagfeltöltés nem igazolja a telepítést. [PR #1044](https://github.com/open-manuscript-initiative/open-manuscript-studio/pull/1044).

**1.0.0-rc.4** · 2026-11-25

A beolvasztott forráskód kibővített Word-kompatibilitást, közvetlen jegyzetbeszúrást, formázott jegyzet-előnézetet és adaptív memóriakezelést tartalmaz. Az RC4 forrásverzió beolvadt; a terjesztési csatornák külön igazolandók.

Előkészített csomagazonosítók, nem közzétett binárisok: Windows MSI/MSIX 1.0.3.0; Android közvetlen versionCode 1600, aláírt workflow 1600 + futásszám; iOS marketing 1.0.0, build 29. A korábban dokumentált web/Android RC2 (1.0.0-rc.2), az állandó asztali 0.3.0-beta.13 és az utoljára igazolt Store 1.0.0.0 külön kezelendő. Pontos SHA-hoz kötött tesztek, aláírt csomagok és tulajdonosi jóváhagyás szükséges.

OMI-SPEC-320@0.3.0 · OJS v1.8.7 / OMP v1.5.1
