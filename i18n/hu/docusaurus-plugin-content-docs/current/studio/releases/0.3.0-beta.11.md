# Open Manuscript Studio 0.3.0-beta.11

Előkészítés dátuma: **2026. október 24.** Ez a kiadás gyorsítja a hosszú dokumentumok szerkesztését, és navigálás közben csökkenti a képernyőn kívüli oldaljelölők kirajzolását. A korábbi kiadások változatlanul megmaradnak.

## Felhasználói változások

- **Élő kiadványszerkesztő:** újra felhasználja a változatlan blokkok sortörési méréseit, és csak a szerkesztéssel érintett tartalmat méri újra.
- **Nyomtatási nézet navigációja:** csak a látható terület és annak közeli környezete körül jeleníti meg az oldaljelölőket, így a hosszú kéziratoknál kevesebb díszítő elem rajzolódik ki.
- **Hordozható formátum:** az OMI kéziratformátum továbbra is `OMI-SPEC-320@0.3.0`.

## Alkalmazásverziók

| Platform vagy szerződés | Verzió |
|---|---|
| Közös Studio / web / natív alkalmazásverzió | `0.3.0-beta.11` |
| Windows MSI termékverzió | `0.3.0.11` |
| iOS / iPadOS rövid verzió | `0.3.0` |
| iOS / iPadOS build | `23` |
| Android ellenőrzött versionCode alsó határ | `1210` |
| Hordozható OMI-formátum | `OMI-SPEC-320@0.3.0` |

Ebben a bétában az OMI fájlformátum nem változik.

## Frissítés és telepítés

A [Studio letöltési oldala](/studio/) mindig a GitHubon közzétett aktuális kiadást követi. A kiadási PR egyesítése után a natív buildmunkafolyamatok az egyesített commitból készítik el a csomagokat. A Google Playhez továbbra is külön Android Release-futtatás szükséges az egyesített `main` ágról; a versionCode értékét ez a futtatás határozza meg. Az iOS nyilvános terjesztéséhez továbbra is szükséges az Apple-aláírás, a provisioning, valamint az eszközös vagy TestFlight-ellenőrzés.

Szervermigrációra nincs szükség.
