# Open Manuscript Studio 0.3.0-beta.8

Kiadás-előkészítés: **2026. október 20.** Ez a kiadás tartalmazza a Word-import címduplázását javító beolvasztott módosítást. A korábban közzétett kiadások változatlanok maradnak.

## A felhasználókat érintő változások

- **DOCX-import:** ha a Word-dokumentum címe az első számozott címsorként is szerepel, a Studio felismeri az ismétlést mind a normál, mind a nagy dokumentumok importálásakor, így a cím nem jelenik meg kétszer.
- **Hordozható formátum:** az OMI kéziratformátum verziója változatlanul `OMI-SPEC-320@0.3.0`.

## Alkalmazásverziók

| Platform vagy formátum | Verzió |
|---|---|
| Közös Studio-, webes és natív alkalmazásverzió | `0.3.0-beta.8` |
| Windows MSI termékverzió | `0.3.0.8` |
| iOS / iPadOS rövid verzió | `0.3.0` |
| iOS / iPadOS build | `20` |
| Android forrásban rögzített versionCode-alapérték | `1207` |
| Hordozható OMI-formátum | `OMI-SPEC-320@0.3.0` |

Az OMI fájlformátuma ebben a bétában nem változik.

## Frissítés és telepítés

A [Studio letöltési oldala](/studio/) az aktuálisan közzétett GitHub-kiadást követi. A kiadási PR beolvasztása után az új csomagok a natív build- és ellenőrzött kiadási munkafolyamatok befejezését követően jelennek meg. A Google Playhez új Android Release futtatás szükséges a beolvasztott `main` ágról; a versionCode ebből a futásból származik. Az iOS nyilvános terjesztéséhez továbbra is Apple-aláírás, provisioning és eszközös/TestFlight-ellenőrzés szükséges.

Ehhez a kliensoldali DOCX-importjavításhoz nincs szükség szervermigrációra. Lásd a [technikai kiadási leírást](https://github.com/open-manuscript-initiative/open-manuscript-studio/blob/main/docs/release/0.3.0-beta.8.md).
