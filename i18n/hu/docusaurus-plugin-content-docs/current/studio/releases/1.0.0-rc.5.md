# Stúdió RC5 — tervezett OJS-lapszámok

**1.0.0-rc.5** · 2026-11-26 · Beolvadt forrásverzió, nem igazolt nyilvános kiadás.

[Studio PR #1089](https://github.com/open-manuscript-initiative/open-manuscript-studio/pull/1089) · [Merged #1088](https://github.com/open-manuscript-initiative/open-manuscript-studio/pull/1088) · [OJS plugin 1.9.1 / #50](https://github.com/open-manuscript-initiative/omi-ojs-plugin/pull/50)

Teljes tervezett lapszám importja a tanulmányok sorrendjével, jegyzetekkel, folyamatjelzéssel és a szerkesztéseket megőrző újraimportálással. Ellenőrzött fizikai PDF-oldaltartományok, tanulmányonként PDF/HTML/JATS Article Authoring XML, jóváhagyott célhoz kötött fájlátvitel és külön nyomtatott oldalszám-visszaírás. A tanulmány-DOI-hoz az OJS-plugin 1.9.1 szükséges. Nincs automatikus publikálás, JATS Publishing megfelelőségi vagy PDF XMP állítás.

Windows MSI/MSIX: 1.0.4.0 · Android versionCode: 2000 (+ workflow run number) · iOS: 1.0.0 / 30 · OMI-SPEC-320@0.3.0

A kompatibilis Stúdió frontend, API és izolált PDF-worker qpdf és Poppler mellett együtt telepítendő. OJS-mentés után a natív ellenőrzéseken átment közzétett TAR.GZ csomaggal frissítsünk. Nem publikált lapszámon ellenőrizzük az azonosítókat, jegyzeteket, oldaltartományokat és nyugtákat. Éles próba és kiadási jóváhagyás még szükséges. Ellenőrizni kell az áruházi számlálókat.

[OJS plugin](/docs/integrations/ojs-plugin) · [Publication editor](/docs/studio/publication-editor)

## Aktuális forrásállapot – 2026. november 27.

Az RC5 beolvadt: teljes tervezett OJS-lapszám importja, tanulmányonkénti szerzőkezelés, többnyelvű címnegyed-shortcode-ok és tanulmányfüggő futó fejlécek. A Stúdió #1090 és #1091, illetve az OJS-plugin #52 és #53 beolvadt. Az OJS main ág verziója 1.9.2.0; az ugyanilyen verziószámú korábbi csomagból a #53 hiányozhat. A csomag eredete és az éles munkafolyamat ellenőrzendő.

Utoljára igazolt hivatkozások: web/Android 1.0.0-rc.2, asztali 0.3.0-beta.13, Store 1.0.0.0; korábbi OJS v1.8.7 és OMP v1.5.1. Nem most ellenőrzött éles verziók.
