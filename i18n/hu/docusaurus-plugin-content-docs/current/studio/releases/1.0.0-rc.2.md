# Open Manuscript Studio 1.0.0-rc.2 — aktuális verziók

Állapot: **2026. november 20.** A Stúdió forrása és webes alkalmazása **1.0.0-rc.2** verziójú. A pontos forráshoz tartozó CI/CD-folyamat éles telepítése sikeresen befejeződött. A novemberi kiadványszerkesztési, jegyzet-, kutatásiprojekt- és OJS-fejlesztéseket a [fejlesztési összefoglaló](/docs/studio/updates/2026-11-20) mutatja be.

## Verziók és terjesztési csatornák

| Csatorna | Ellenőrzött verzió és elérhetőség |
| --- | --- |
| Webes Stúdió | **1.0.0-rc.2**, sikeres telepítés november 20-án |
| Közvetlen Android APK-jelölt | **1.0.0-rc.2**, a natív buildben aláírt és ellenőrzött APK, Actions ZIP-csomagban |
| Natív Windows/Linux/macOS-jelöltek | Az RC2-csomagok sikeresen elkészültek, külön Actions-állományokként |
| Állandó közvetlen asztali kiadás | A legutóbbi közzétett GitHub-kiadás továbbra is **0.3.0-beta.13**, EXE/MSI/AppImage/DEB/DMG fájlokkal |
| Előkészített Windows MSI / Store MSIX | **1.0.1.0**; a csomagverzió nem igazolja az áruházi frissítés megjelenését |
| Utoljára külön igazolt Store-verzió | **1.0.0.0**, november 10-i felhasználói ellenőrzés; a mostani áruházi frissítést ez az összefoglaló nem ellenőrizte újra |
| Kísérleti iOS-forrás | **1.0.0**, build **27**; ebből nem következik új TestFlight/App Store-megjelenés |
| OJS-bővítmény | **v1.8.7**, közzétéve november 18-án |
| OMP-bővítmény | **v1.5.1** |
| Hordozható kéziratformátum | **OMI-SPEC-320@0.3.0**, változatlan |

[Webes Stúdió megnyitása](https://studio.openmanuscript.org). [Aláírt Android RC2-jelölt letöltése ZIP-ben](https://github.com/open-manuscript-initiative/open-manuscript-studio/actions/runs/44704656922/artifacts/14615141484). Csomagold ki és telepítsd az APK-t; GitHub-bejelentkezés szükséges lehet. Az Actions-csomag **2027. február 18-án lejár**, nem állandó kiadási fájl. A ZIP ellenőrzőösszege: `sha256:0b516bd12089878fb9066f5f95c069d91ef99e8a080f0390b83ecb89e0280020`; ez a ZIP-et azonosítja, nem külön az APK-t.

Az önálló Android Release-folyamat is sikeres ugyanezen a forráson. Ez önmagában nem igazolja a Google Play nyilvános megjelenést vagy frissítést. Az általános frissítő közzétett kiadási csatornája elkülönül az RC-csomagoktól.

A natív csomagok Windows x86-64, Linux x86-64, macOS Intel/Apple Silicon és Android célra készültek. A forrásban az Android közvetlen versionCode minimuma **1359**; az Android Release saját, futásonként növekvő kódot állít elő. Az RC2 előkészítése november 11-én kezdődött; a fenti futások a november 20-ig beolvadt fejlesztéseket is tartalmazzák.

A CI és a sikeres build nem helyettesíti a készüléktesztet, nyomdai próbát, áruházi aláírást/terjesztést és a stabil 1.0 jóváhagyását. A natív Linux és macOS Preview, az iOS/iPadOS kísérleti marad. Az örökölt Linux GLib-ügy külön követett. Az [RC1 vizsgálatai](/docs/studio/releases/1.0.0-rc.1) történeti eredmények, nem kerültek átminősítésre RC2-elfogadássá.
