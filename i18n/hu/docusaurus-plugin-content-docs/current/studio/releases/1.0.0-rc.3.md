# Stúdió 1.0.0-rc.3 – forráskódjelölt

**Előkészítés: 2026. november 23.** A [#972-es kiadási PR](https://github.com/open-manuscript-initiative/open-manuscript-studio/pull/972) a [#971-es EuroOffice-szétválasztást](https://github.com/open-manuscript-initiative/open-manuscript-studio/pull/971) tartalmazó új, egységes verziójú buildet készíti elő. **Ez még nem igazolt nyilvános GitHub-kiadás és nem Store-frissítés.** Az RC1/RC2 készüléktesztjei és aláírási jóváhagyásai nem érvényesek automatikusan az RC3 csomagjaira.

## Mit tartalmaz a forráskód?

Kikerült az általános EuroOffice-szerkesztő beágyazása és API-kapcsolata. A Stúdió saját DOCX/ODT-importja és -exportja, a tudományos szövegszerkesztés, jegyzetkezelés, kiadványszerkesztés és OJS/OMP-munkafolyamatok megmaradnak. Az EuroOffice önállóan működik. Részletek: [architektúra](/docs/studio/office-separation).

## Verziócsatornák

| Csatorna | Állapot |
| --- | --- |
| RC3 fejlesztői forráskód | `1.0.0-rc.3`, kiadási jóváhagyás még nincs |
| Korábban dokumentált webes/Android APK | `1.0.0-rc.2`; az éles RC3 telepítést külön igazolni kell |
| Állandó GitHub-telepítők | `0.3.0-beta.13` új tagelt kiadásig |
| Windows MSI/MSIX előkészített azonosító | `1.0.2.0`; **nem** igazolt Store-kiadás |
| Microsoft Store – utoljára igazolt | `1.0.0.0` |
| OJS / OMP bővítmények | `v1.8.7` / `v1.5.1` |
| Hordozható fájlformátum | `OMI-SPEC-320@0.3.0` |

Az Android közvetlen APK verziókódja legalább **1395**, a külön aláírt Play AAB változaté **1205 + futásszám**. A kísérleti iOS build **28**, marketingverziója **1.0.0**.

A `v1.0.0-rc.3` végleges GitHub prerelease-hez azonos forráskódhoz tartozó natív buildek, aláírás, ellenőrzött fájlkivonatok, E02-bizonyítékok, tizennégy kézi ellenőrzés és végső tulajdonosi Go/No-Go szükséges. **A letöltési URL-eket csak ellenőrzött csomagok után szabad megváltoztatni.**
