# Open Manuscript Studio 0.3.0-beta.9

Kiadás-előkészítés: **2026. október 24.** Ez a kiadás tartalmazza a Linuxos mélyhivatkozás-javítást, valamint a holland és lengyel fordításokat. A korábban közzétett kiadások változatlanok maradnak.

## A felhasználókat érintő változások

- **Linuxos mélyhivatkozások:** a regisztráció és a lekérdezés most egyértelmű I/O-hibát jelez. Az eltávolítás csak az alkalmazás saját MIME-társítását törli, a többi alkalmazásét megőrzi.
- **Fordítások:** bekerültek a Studio közös felületének és kutatási moduljainak visszaküldött holland és lengyel fordításai.
- **Hordozható formátum:** az OMI kéziratformátuma változatlanul `OMI-SPEC-320@0.3.0`.

## Alkalmazásverziók

| Platform vagy formátum | Verzió |
|---|---|
| Közös Studio-, webes és natív alkalmazásverzió | `0.3.0-beta.9` |
| Windows MSI termékverzió | `0.3.0.9` |
| iOS / iPadOS rövid verzió | `0.3.0` |
| iOS / iPadOS build | `21` |
| Android forrásban rögzített versionCode-alapérték | `1208` |
| Hordozható OMI-formátum | `OMI-SPEC-320@0.3.0` |

Az OMI fájlformátuma ebben a bétában nem változik.

## Frissítés és telepítés

A [Studio letöltési oldala](/studio/) az aktuálisan közzétett GitHub-kiadást követi. A kiadási PR beolvasztása után a natív buildfolyamatok az egyesített commitból készítik el a csomagokat. A Google Playhez külön Android Release-futtatás szükséges az egyesített `main` ágról; a versionCode ebből a futásból származik. Az iOS nyilvános terjesztéséhez továbbra is Apple-aláírás, provisioning és eszközös/TestFlight-ellenőrzés szükséges.

Ehhez a kiadáshoz nincs szükség szervermigrációra.
