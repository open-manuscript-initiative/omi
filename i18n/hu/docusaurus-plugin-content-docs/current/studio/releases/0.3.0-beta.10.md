# Open Manuscript Studio 0.3.0-beta.10

Kiadás-előkészítés: **2026. október 24.** Ez a kiadás a hosszú kéziratok lapozása közben is használhatóvá teszi az élő kiadványszerkesztőt. A korábban közzétett kiadások változatlanok maradnak.

## A felhasználókat érintő változások

- **Hosszú dokumentumok lapozása:** a nyomtatási elrendezés a kéziratblokkokat és lábjegyzeteket rövid, megszakítható képkockánkénti lépésekben méri, így a felület a mérési szakaszok között reagálni tud.
- **Hordozható formátum:** az OMI kéziratformátuma változatlanul `OMI-SPEC-320@0.3.0`.

## Alkalmazásverziók

| Platform vagy formátum | Verzió |
|---|---|
| Közös Studio-, webes és natív alkalmazásverzió | `0.3.0-beta.10` |
| Windows MSI termékverzió | `0.3.0.10` |
| iOS / iPadOS rövid verzió | `0.3.0` |
| iOS / iPadOS build | `22` |
| Android forrásban rögzített versionCode-alapérték | `1209` |
| Hordozható OMI-formátum | `OMI-SPEC-320@0.3.0` |

Az OMI fájlformátuma ebben a bétában nem változik.

## Frissítés és telepítés

A [Studio letöltési oldala](/studio/) az aktuálisan közzétett GitHub-kiadást követi. A kiadási PR beolvasztása után a natív buildfolyamatok az egyesített commitból készítik el a csomagokat. A Google Playhez külön Android Release-futtatás szükséges az egyesített `main` ágról; a versionCode ebből a futásból származik. Az iOS nyilvános terjesztéséhez továbbra is Apple-aláírás, provisioning és eszközös/TestFlight-ellenőrzés szükséges.

Szervermigrációra nincs szükség.
